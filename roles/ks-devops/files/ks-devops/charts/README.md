The `ks-devops-0.2.3.tgz` in this directory is vendored for offline installs; it was published at
https://github.com/kubesphere-sigs/ks-devops-helm-chart/releases/download/ks-devops-0.2.3/ks-devops-0.2.3.tgz

To use another version, replace the tgz and update `ks_devops_chart_version` in
`roles/ks-devops/tasks/main.yaml`.

Get the helm chart of Argo CD from https://github.com/argoproj/argo-helm/releases
